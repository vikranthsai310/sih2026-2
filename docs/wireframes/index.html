One pass. One video. A measurable 3D world.

Mid-fidelity, click-through prototype of the Drishti3D web app (React + CesiumJS in production). It implements the screens in 09 · Viewer and UI with the tokens in 18 · Design System. Works offline: open this file directly, no server or network needed.

Use the dark bar at the top: theme (Field dark / Analyst light), viewport (desktop, tablet 1024 px, phone 390 px read-only), language (EN / हि for key labels) and Notes (numbered annotations). Choices are remembered in this browser. All accuracy numbers are example values. Details: README.

How to read these wireframes

Yellow numbered pins on each screen map to the notes in this panel. Toggle them with Notes.
  1. Mid-fidelity: layout, hierarchy, copy, states and behaviour are intended; the 3D scene is a stylised SVG town (river, bridge, roads, buildings, trees, flight strip).
  2. Click-through: every screen links to the next step of the flow; the top bar has previous / gallery / next.
  3. Responsive: the viewport switch uses container queries, so the tablet (drawers, icon rail) and phone (read-only) layouts are real, not screenshots.
  4. Interactive bits: layer toggles (05), measurement tools (06), swipe/compare modes (10), dialogs, menus, toasts, log tabs.
