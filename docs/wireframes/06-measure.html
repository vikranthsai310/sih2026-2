06 · Measurement tools

09 §5.5 toolbar + §6 · Persona: analyst · POST /api/v1/runs/{id}/measurements, POST …/measure/{volume|area|profile}
  1. Toolbar is live here: click a tool or press S D H A V P C B; Esc returns to Select. Each tool shows its own canvas drawing, hint line and result card.
  2. Distance: 3D slant (default), horizontal (geodesic) and grid (UTM, with scale factor k). Value and ± stay together, and Copy copies both with the level.
  3. Height with the inferred flag: one pick lands on an LoD2-completed facade, so the result is tagged (hatched chip) and σ jumps to σ_inferred. The guard suggests a better pick.
  4. Volume shows cut / fill / net and the base method. Large polygons run on the server. Numbers mirror the 08 §9.3 example.
  5. Coordinates are absolute: CE90/LE90 of the run combined with local noise, the tier, and lat/lon + UTM + MGRS. GNSS-only runs get a red badge.
  6. Inferred geometry is excluded from snapping unless the user opts in (09 U4).
  7. Splat-only: measuring tools are disabled and the reason is shown in words (09 U5). Try it from the Select panel.
