09 §12 · all personas · error model 08 §9.4 (RFC 7807 with code + remedy)
  1. Server unreachable: top chip turns danger and a banner explains that the job keeps running on the server. Reconnect replays WebSocket events with since_seq.
  2. Loading: skeletons for lists, never an endless spinner for long work.
  3. No telemetry: red banner, the relative-only path is offered as a secondary action with explicit wording.
  4. Stage failure: failed stage red, later stages skipped, plain-language cause, suggested fix and "Retry from Sn" (POST …/resume {from_stage}).
  5. No checkpoints: values italic with "est.", status ~ not PASS, and a direct way to add checkpoints.
