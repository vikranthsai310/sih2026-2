03 · Ingest Check (S0 result)

09 §5.3 · Persona: field operator · GET /api/v1/missions/{id}/ingest-check
  1. Overall verdict first, in words: pass / usable with warnings / fail. Target: shown ≤ 30 s after the SRT and video header arrive.
  2. GPS track over the offline base (reference ortho or run-local tiles). Altitude uses one hue, light → dark. Gaps > 2 s warn; > 50 % without GPS fails.
  3. Time sync: value ± 1σ, method, and the correlation curve with the peak marked. A flat peak (peak / 2nd < 1.2) or |offset| > 2 s warns. Override is logged in the report.
  4. Frame quality histogram with the auto threshold. Rejected bins use the warn colour and sit left of the labelled threshold line. Warn if > 5 % blurred; fail if < 50 keyframes survive.
  5. Checks use icon + text for each state (✓ / ⚠ / ✗ / ℹ). Warnings never block.
  6. Timeline shows where the problems are in the clip, with a text legend and a hatched pattern for "no GPS".
  7. Start processing is disabled only on a fail. Calls POST /api/v1/runs with {mission_id, profile, inputs, options, overrides} and an Idempotency-Key.
